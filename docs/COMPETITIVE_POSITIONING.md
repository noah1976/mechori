# COMPETITIVE_POSITIONING

## 文書の目的

MECHORIが、既存の愛車管理・自動車SNS・検索サービスと重なる部分を認めたうえで、何を中核にし、何を競争しないかを固定します。

競合の弱点を並べるための文書ではありません。後発サービスとして、利用者が既に使っている投稿先、記録先、検索先へ追加してでも使う理由を失わないための判断基準です。

## 一文の位置づけ

> 愛車の出来事を一台の履歴として残し、その実体験を次の整備と次の同型車へ生かす基盤。

MECHORIの入口には写真、プロフィール、現在と過去の愛車歴、フォローがあります。しかし、人気、イベント参加、滞在時間を中核価値にはしません。

記録が次の整備へ使われ、対応後の結果が再び履歴と根拠付きナレッジへ戻ることを中核にします。

## MyGarageとの重複と境界

2026年7月24日に確認したMyGarageのApp Store上の説明では、現在・過去の所有車、スペックシート、複数台管理、イベント、グループ、行動予定の管理が主な機能として示されています。

MECHORIと重なる領域:

- 現在と過去の愛車プロフィール
- 複数台の管理
- 写真とカスタム情報
- オーナー間で愛車を見せる体験

正面から競争しない領域:

- イベント運営
- クラブ・グループ管理
- 行動予定・カレンダー
- 人気や交流量を主目的にしたSNS機能

MECHORIが検証する固有領域:

- 整備、故障、部品、結果を一台の履歴へ接続する
- 正確な日付を覚えていない過去記録も、精度を偽らず残す
- 車種・世代・仕様・市場名の一致範囲を分ける
- 同型車の公開事例を、出典、確認状態、反対結果付きで探す
- 対応後の結果を追記し、次の事例へ還元する
- 将来、オーナー履歴を工場の受付・作業報告へ引き継ぐ

参考:

- MyGarage App Store: <https://apps.apple.com/jp/app/mygarage-%E3%83%9E%E3%82%A4%E3%82%AC%E3%83%AC%E3%83%BC%E3%82%B8/id1277230151>

## 他の代替手段

競合は自動車アプリだけではありません。

| 既存行動 | 利用者が得ている価値 | MECHORIが追加で成立させる価値 |
| --- | --- | --- |
| 写真SNS・自動車SNSへ投稿 | 見てもらう、交流する | 写真を車両、時期、前後の整備へ接続する |
| メモ・表計算・紙で管理 | 自分の履歴を保存する | 車両仕様と出典を保ったまま検索・共有できる |
| Googleや動画で検索 | 広い情報から手掛かりを探す | 自車との一致範囲、結果、反対事例を比較する |
| 一般AIへ質問 | 早く要点を得る | 自車履歴と許諾済み実例を根拠にし、結果まで回収する |
| 工場へ相談 | 実車を確認してもらう | 受付前に車両仕様と過去履歴を渡し、完了記録を戻す |

一般AIより詳しい文章を書くこと自体を差別化にはしません。個体履歴、出典、許諾、確認状態、対応後の結果が循環することを差別化にします。

## UIとコピーの基準

- 未ログインの最初の画面で、愛車管理だけでなく「次の整備へ使える履歴」だと分かる。
- 写真や思い出の楽しさを残しつつ、写真SNSが主役だと誤認させない。
- AI検索・自動翻訳・実在ナレッジなど、未提供機能を現在形で約束しない。
- 競合名や競合批判を利用者向けコピーへ出さない。
- 「原因を特定する」「修理方法を教える」ではなく、実例、一致範囲、確認箇所、結果を示す。
- Journal、フォロー、反応が履歴またはナレッジへつながらない場合、利用頻度だけを理由に拡張しない。

## αで確認すること

初回利用後、機能名を説明してから質問しません。次を本人の言葉で確認します。

1. 最初の画面を見て、何のサービスだと思ったか。
2. 愛車プロフィールだけのサービスと何が違うと思ったか。
3. 自分の過去の整備・故障・部品・結果を、追加しておく理由を感じたか。
4. 困ったときに、一般検索とは別にMECHORIを開く場面を想像できたか。
5. 検索を故障診断や修理指示だと誤認しなかったか。

3人中2人以上が、説明なしで「履歴」「整備」「同型車の経験」のうち二つ以上を挙げられない場合、機能追加より先に入口の文言と導線を修正します。

## 機能追加の判断

新機能は、次の少なくとも一つを強くする場合だけ初期候補にします。

1. 一人でも愛車履歴を残す価値
2. 同型車・近い仕様の実例を探す価値
3. 対応結果を次のオーナーへ返す価値
4. オーナーと工場の間で履歴を途切れさせない価値

イベント、DM、グループ、ランキング、長時間滞在だけを強くする機能は、初期範囲へ追加しません。
