# ALPHA_LAUNCH_CHECKLIST

## 凡例

- `[x]` 実装・人間QA済み
- `[~]` 実装済み・人間QA待ち
- `[ ]` 未実装または未完了
- `[-]` 今回対象外・延期・撤回

このチェックリストは、人間QAを省略して実装済み機能を完了扱いにしない。コード、テスト、本番反映、人間QAは別々に確認する。現在のα確認先は `https://mechori-alpha.netlify.app`。
