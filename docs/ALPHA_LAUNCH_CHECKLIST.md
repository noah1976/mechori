# ALPHA_LAUNCH_CHECKLIST

## この文書の目的

MECHORIを特に親しい3〜5人へ渡すとき、所有者が行う作業だけを短くまとめます。詳しい安全条件と評価方法は`ALPHA_PLAYBOOK.md`、初期管理設定は`ALPHA_OWNER_BOOTSTRAP.md`を参照します。

## 初回だけ確認

1. Netlifyの公開先が`https://mechori-alpha.netlify.app`であることを確認する。
2. Supabaseが`mechori-alpha`であることを確認する。
3. `202607220001_member_invitations.sql`が適用済みか確認する。MECHORIの`招待`画面でURLを発行できれば適用済み。
4. `202608030001_alpha_operations_foundation.sql`が適用済みか確認する。`owner`ロールのアカウントで`/admin`を開き、運営サマリーが表示されれば適用済み。
5. 自分のGoogleアカウントで、ログアウト確認、ログアウト完了画面、再ログイン、既存データの再表示を確認する。
6. `招待`、`感想`、愛車登録、愛車情報編集、整備記録追加・編集を自分で1回ずつ開く。

この確認で失敗した場合は、新しいテスターを追加せず、画面と発生時刻だけを記録します。招待コード、Client Secret、DBパスワードは記録しません。

## 1人招待するたびに行うこと

1. 本人がログインに使うGoogleアカウントを、普段の連絡手段で確認する。
2. MECHORIへログインし、上部の`招待`から1人用URLを1本発行する。
3. 招待画面に「Google OAuthはテスト中」と表示される場合だけ、Google Auth Platformの`対象`で、そのアカウントをテストユーザーへ追加する。
4. 下の依頼文とURLを本人だけへ送る。SNSへ公開投稿しない。
5. その人が参加できたら、次の人には新しいURLを発行する。

Google OAuthを`本番環境`へ公開し、Netlifyの`NEXT_PUBLIC_GOOGLE_OAUTH_PUBLISHING_STATUS`を`production`へ変更した後は、Googleテストユーザー追加を省略できます。MECHORIの招待権限は別の安全ゲートとして残ります。

## そのまま使える依頼文

```text
個人で作っているMECHORI（メカリィ）の小さなαテストに付き合ってください。

まず、自分のクルマかバイクを1台登録して、過去の整備かドライブを1件だけ残してみてほしいです。車種が候補になくても自由入力できます。写真や正確な日付がなくても大丈夫です。

まだα版なので、車検証、整備明細の原本、住所、ナンバーが読める写真は入れないでください。分かりにくい、動かない、ちょっと良いと思ったところは、ログイン後の「感想」から一言もらえると助かります。

このURLはあなた1人用です：
［ここに招待URL］
```

## テスターに試してもらう最小範囲

1. 招待URLからGoogleで参加する。
2. 現在または過去のクルマ・バイクを1台登録する。
3. `さっと記録`で写真または一言を1件残す。
4. 整備記録を1件残す。正確な日付を覚えていなければ、年月ごろ・年ごろ・時期不明を選ぶ。
5. 保存した記録を編集する。
6. 一度ログアウトし、同じGoogleアカウントで戻る。
7. 上部の`感想`から、良かった点か迷った点を1件送る。

## 更新後の人間用QA

デプロイ後は、所有者と可能なら別の参加者で次を確認します。内部UUID、招待トークン、秘密情報は記録しません。

1. Googleログイン、新規ユーザーの`@username`設定、招待経由登録と招待者との相互ユーザーフォロー
2. 表示名・`@username`による人の検索、ユーザーフォロー、個別車両フォロー、解除後の独立性
3. 両方をフォローした場合もフィードに同じ投稿が重複しないこと
4. 他人のJournalでいいね追加・解除が即時反映され、再読み込み後も一致すること
5. 公開プロフィールで表示名、`@username`、bio、公開中の愛車・投稿だけが表示されること
6. bioへメールアドレスや電話番号を入力すると、内容を失わず拒否されること
7. 型式なしのクルマ、バイク、過去車を登録できること
8. 愛称、所有開始時期、メイン写真を追加・変更・削除でき、縦長・横長写真の全体を確認できること
9. iPhoneの`さっと記録`、愛車登録、愛車編集で、`カメラで撮る`と`写真から選ぶ`がそれぞれ意図した入力元を開くこと
10. 写真付きの`さっと記録`、愛車登録、愛車編集で、保存直後にボタンが回転表示へ変わり、8秒を超える場合は保存継続中の案内が出ること
11. ログイン後ホーム、デスクトップの常設追加ボタン、フォロー中画面の`さっと記録`から、現在選択中の愛車の写真・一言入力へ直接進めること
12. 別端末で共有写真を表示でき、一時的な通信失敗後も自動再試行または`再読み込み`で復帰できること
13. ログアウト前に確認があり、完了後に専用画面へ移ること
14. `感想`の送信成功と、失敗時の入力保持・再試行を確認すること
15. `/admin`でフィードバック確認とFounding TesterのOwner Plus付与・停止ができ、一般参加者は運営情報を取得できないこと
16. favicon、ホーム画面追加時のApple Touch Icon、スマートフォン表示を確認すること
17. GTM Previewで`page_view`等を確認し、GA4 RealtimeとClarityの両方で閲覧を確認すること

管理画面のロール・利用権変更には必ず理由を入力します。利用権の付与対象は表示名または`@username`で本人を確認し、内部IDをチャットへ貼りません。

操作方法を先に詳しく教えすぎず、安全上の禁止事項だけを伝えます。迷った場所そのものがαの重要な結果です。

## 所有者が残す最小メモ

個人情報を含めず、各テスターについて次だけを手元のメモへ残します。

- 招待日
- ログイン完了の可否
- 愛車登録完了の可否
- 記録追加・編集完了の可否
- 再ログイン完了の可否
- 最も迷った箇所
- もう一度使う場面

利用者のGoogleアカウント、車両の詳細、整備内容を進捗管理用の文書へ転記しません。
