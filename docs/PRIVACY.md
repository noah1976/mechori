# PRIVACY

## 基本方針

各国の個人情報保護法制への対応負担を最小化するため、Privacy by Design とデータ最小化を基本原則にします。サービス提供に不可欠でない個人情報は取得・保存しません。

## 原則として保持しない情報

- 氏名
- 住所
- 電話番号
- 生年月日
- ナンバープレート番号
- VIN・車台番号全文
- 正確な位置情報
- GPS移動履歴
- 運転免許証等の本人確認書類
- クレジットカード情報
- 整備記録簿や領収書の原本
- 外部AI処理に不要な個人情報

## 初期実装

- 匿名またはハンドルネームを基本にする。
- 認証情報とアプリケーションデータを分離する。
- アプリケーションDBでは内部ユーザーIDを使う。
- ユーザーID単位で関連データを抽出し、削除または匿名化できる関連と識別子を設ける。
- データの作成日時と更新日時を保持できるようにする。
- 公開ナレッジと非公開の個人整備記録を分離する。
- 同意した利用規約・プライバシー方針のバージョンと日時を保持できるようにする。
- OCR原本画像・PDFは標準で恒久保存せず、一時処理後に削除する方針にする。
- 原本・一時ファイルに削除期限と削除状態を設定できるようにする。
- 保存対象は、ユーザーが確認した構造化データを基本にする。
- 外部サービスへ送った処理について、送信先、処理目的、対象データ、処理日時、削除状態を必要最小限の情報で追跡できるようにする。

## アカウント削除時の基本方針

- 非公開の個人整備記録は原則として削除する。
- 公開ナレッジは個人との関連を解除し、十分に匿名化できる場合のみ保持を検討する。
- 画像や自由記述は、個人識別要素を除去できなければ削除する。
- 法的保全対象は通常の削除対象と分け、根拠、対象範囲、アクセス権限、保全期限を管理できるようにする。
- 外部サービス上の派生データや一時ファイルも削除対象として追跡する。

画面の実装を後段にしても、これらの処理をユーザー単位で実行できるデータ境界は初期設計から設けます。匿名化による保持の可否や法的保全の具体的要件は、公開前に対象地域の法令と専門家の確認を受けます。
