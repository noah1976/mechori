# ROADMAP

## Phase 0: 設計文書とルール整備

- `AGENTS.md` と `docs/` の初期文書を作成する。
- プロダクト、安全、プライバシー、法務、AI、収益化の基本方針を揃える。
- 未確定事項を `docs/BACKLOG.md` に整理する。

## Phase 1: 初期MVP設計

- データモデル案を作成する。
- 画面一覧と主要導線を定義する。
- 初期Webアプリ構成を決める。
- Supabase、Vercel、OpenAI API 等を使う場合は初心者向け手順書を作成する。
- 料金、無料枠、停止方法を確認する。

## Phase 2: Web MVP 実装

- スマートフォン向けWebアプリを実装する。
- 匿名またはハンドルネームのアカウントを実装する。
- 愛車登録、整備イベント、作業の親子構造を実装する。
- 公開／非公開、検索、安全警告を実装する。
- 日本語／英語の基礎を実装する。

## Phase 3: 管理・安全・公開準備

- 投稿確認、一時非公開、通報、削除理由を整備する。
- 利用規約、プライバシーポリシー、投稿ガイドラインを準備する。
- RLS、バックアップ、ログ、復元テストを確認する。
- 公開前レビューを行う。

## Phase 4: AI/OCR 補助

- OCR結果の構造化補助を検討する。
- AIタグ候補、翻訳、重複候補、個人情報候補検出を検討する。
- AI出力を人間が確認してから保存する画面を実装する。

## Phase 5: 拡張

- 他車種・他メーカー・バイク等へ拡張する。
- メカニック確認済み情報を扱う。
- Expo / React Native 追加を検討する。
- 収益化、税務出力、整備工場向け機能を検討する。
