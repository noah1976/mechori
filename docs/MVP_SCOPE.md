# MVP_SCOPE

## 初期MVPで想定する機能

- 匿名またはハンドルネームによるアカウント
- 愛車登録
- 整備イベント登録
- 1回の入庫に複数作業を紐付けられる親子構造
- 症状、原因候補、確認内容、作業、部品、結果の構造化
- 公開／非公開
- 同車種・同年式・同エンジン・部品番号・症状による検索
- 日本語／英語
- 整備記録簿、明細、PDF、画像等の将来の一括取り込みに備えた設計
- OCR／AI抽出結果を人間が確認してから保存する仕組み
- 管理者による投稿確認・一時非公開化
- 将来の無料版／有料版の権限差を追加できる構造

## 初期MVPで実装しないもの

- 全世界の車種マスタ
- AIによる故障診断・修理指示
- ネイティブアプリ
- メカニックへの有料相談
- 工場予約
- 部品販売
- Stripe決済
- 広告SDK
- リアルタイムチャット
- 汎用的なSNSタイムライン
- VINによる完全自動識別

## 初期実装

- FIAT Barchetta を前提に、車両、整備イベント、作業、症状、部品、結果を記録できる最小構成を検討する。
- 検索軸は、車種、年式、エンジン、部品番号、症状を優先する。
- AIやOCRの結果は、ユーザー確認前の下書きとして扱う。

## 将来拡張

- 車種マスタの拡張
- 端末内OCR
- 外部AIを使った構造化補助
- メカニック確認済み情報の扱い
- 無料版／有料版の権限差

## 公開前対応

- 公開範囲、通報、管理者非公開化の導線
- 安全警告の表示条件
- 個人情報を含む画像・PDFの扱い
- 利用規約、プライバシーポリシー、投稿ガイドライン
