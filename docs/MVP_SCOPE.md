# MVP_SCOPE

## 初期MVPで想定する機能

- 匿名またはハンドルネームによるアカウント
- 車種マスタの有無にかかわらず完了できる、メーカー・車種自由入力の愛車登録
- 整備イベント登録
- 1回の入庫に複数作業を紐付けられる親子構造
- 症状、原因候補、確認内容、作業、部品、結果の構造化
- 公開／非公開。新規整備記録の公開デフォルトは非公開
- 同車種・同年式・同エンジン・部品番号・症状による検索
- 日本語／英語
- 整備記録簿、明細、PDF、画像等の将来の一括取り込みに備えた設計
- OCR／AI抽出結果を、ユーザー確認前は下書きまたは未確認状態として扱う仕組み
- 共有ナレッジとして公開する情報の管理者確認・一時非公開化
- 将来の無料版／有料版の権限差を追加できる構造
- Garage Journalの自由記述と構造化整備記録を分離し、任意で関連付けられる境界
- プロフィール、車両、車種を対象とするフォロー関係を将来追加できる境界

## 初期MVPで実装しないもの

- 全世界の車種マスタ
- 車種マスタへの登録完了依存、未登録車種の承認待ち
- AIによる故障診断・修理指示
- ネイティブアプリ
- メカニックへの有料相談
- 工場予約
- 部品販売
- Stripe決済
- 広告SDK
- リアルタイムチャット
- コメント、DM、グループ、リポスト、ランキングを含む汎用的なSNS
- AIによるGarage Journal本文の自動生成
- VINによる完全自動識別

## 初期実装

- FIAT Barchetta を前提に、車両、整備イベント、作業、症状、部品、結果を記録できる最小構成を検討する。
- 検索軸は、車種、年式、エンジン、部品番号、症状を優先する。
- AIやOCRの結果は、確認済み事実または公開ナレッジとして自動確定しない。ユーザー確認前は下書きまたは未確認状態とし、確認後に確定状態へ変更する。
- 新規整備記録の公開デフォルトは非公開とし、ユーザーが内容を確認して明示的に公開する。
- 招待制ベータ中は、共有ナレッジとして公開する情報を管理者が確認できるようにする。
- 個人の非公開整備記録には事前審査を行わない。
