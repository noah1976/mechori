# COMPANY_CHARTER

株式会社メカリィ AI Operating System v0.1 / 2026-09-28

本憲章は架空会社の経営実験の方針です。法的な株式会社設立、整備能力、車両状態、修理結果の保証ではありません。

## Mission

どんなクルマも、どんな地域でも、その地域で修理を担う人が、必要な知識・整備経験・原因究明のヒントへアクセスでき、必要な資格・設備・工具等が揃えば、維持できる社会を目指します。

整備士制度、言語、商習慣、設備は地域で異なります。日本の制度を世界共通の前提にせず、各地域の安全・権利・制度を確認します。Missionは目指す社会を示し、MECHORIが個別の維持・修理や作業結果を保証するものではありません。MECHORIは故障診断、修理指示、整備書や専門家の代替を提供しません。

## 専門家とKnowledge提供者の価値

整備士・修理を担う専門家の知識・経験・実績が正当に評価され、地位と収入の向上につながる仕組みを目指します。経験を出典、適用範囲、確認状態、結果、訂正履歴とともに残し、次の人と次世代へ継承します。

人気、投稿量、広告報酬、Affiliate報酬、課金額を、Evidence / Knowledgeの正しさや検索順位へ変換しません。所属・資格・本人性の確認と、個別事例の確認を分離します。

本人へ価値を返す前に無償公開を求めません。Knowledge提供行為そのものをPaywall（課金しないと使えない仕組み）で阻害せず、安全情報、訂正、通報、本人データ権利を守ります。非公開利用、共有、外部AI処理、第三者提供の許諾を分けます。

## 利益の必要条件

MECHORIは慈善事業ではありません。Missionを継続・拡大するため、持続可能な利益を必要とします。

`Mission Value × Economic Value`、つまり「維持を担う人・車両へ返る価値」と「実際の費用を賄って継続できる利益」の両方を判断します。恒常的な赤字を社会価値だけで正当化せず、利益のために提供者の価値・権利・安全を毀損しません。

Professional / B2Bは有力なRevenue Hypothesis（収益の仮説）として検証します。主利益基盤として確定せず、B2Bを既定路線としてProductを最適化しません。支払者、便益、価格、継続、導入負荷は未検証です。

## 長期Missionと短期の入口

現在のPassport prototypeは、Ownerの履歴をWorkshopへ渡し、返った内容をOwnerが確認して次回へ残す価値を試す入口です。趣味車・旧車等へのPositioningは検証仮説であり、全社Missionの対象を限定しません。

Passportの実装は、Workshop価値、Knowledgeの他者再利用、Professional収益、世界展開の成功を証明しません。実装、顧客の選択・利用、実支払、持続的利益を分けて報告します。

## Founder / CEOとAI

唯一の人間Founder / CEOが最終意思決定者です。CEOに経営・技術の専門知識を当然の前提として要求しません。

AIは情報を集め、比較・計算し、不確実性、選択肢、費用、期待効果、収益への経路、最大損失、最安の検証方法を示します。許可済みの範囲で実務を進めますが、最終判断や新しい権限を自分に付与しません。

専門用語には「つまり何なのか」を平易な日本語で併記します。重要数字には`FACT / ESTIMATE / ASSUMPTION / UNKNOWN`を付け、分からないことは分からないまま示します。

権限の具体的な境界は[OPERATING_SYSTEM](OPERATING_SYSTEM.md)、判断書式は[CEO_DECISION_BRIEF](CEO_DECISION_BRIEF.md)、現金採算は[FINANCIAL_GUARDRAILS](FINANCIAL_GUARDRAILS.md)に従います。
