# FINANCIAL_GUARDRAILS

株式会社メカリィ AI Operating System v0.1 / 2026-09-28

## 目的と数字の分類

MECHORIは慈善事業ではありません。Missionを継続・拡大するために持続可能な利益を必要とし、Missionと矛盾する収益化は行いません。

| 分類 | 使用条件 |
| --- | --- |
| `FACT / 実績・確認事実` | 実売上、入金、請求、利用量等に根拠がある。CEO設定のルール額は「設定額」と明示し、実費と区別 |
| `ESTIMATE / 推定` | 根拠と計算式から求めた見積もり。入力値の分類・範囲、除外項目、確認日を付ける |
| `ASSUMPTION / 仮定` | 未検証の条件やシナリオ。需要、価格、転換、継続等を事実として扱わない |
| `UNKNOWN / 未検証` | 根拠がない、または未確認。ゼロへ置換せず、必要な確認を明記 |

重要数字には、対象期間、通貨、税込／税抜、為替・手数料、分母、出典・確認日を付けます。FACTと仮定から作った将来予測はFACTへ昇格させません。請求書や個人情報をGit・PR・分析ログへ複製せず、許可済みの証拠への参照と必要最小限の集計を使います。

## 収益仮説と過去価格

Professional / B2Bは有力な`CURRENT HYPOTHESIS`です。誰が何にいくら支払い、継続し、導入負荷に見合うかはUNKNOWNです。Owner有料機能、Affiliate、広告、相談・Knowledge利用の対価も、実績が確認されるまでは収益仮説として扱います。

[BUSINESS_MODEL](../BUSINESS_MODEL.md)、[MONETIZATION](../MONETIZATION.md)、[Strategy v2](../STRATEGY_REVIEW_V2_2026-09.md)等の既存料金候補は、すべてHistorical Pricing Hypotheses（過去の価格仮説）です。現在価格、採用済み価格、Revenue Planの基準値として使用しません。

価格Decisionは、顧客価値、実需要、実費、競争代替、支払意思と決裁条件を確認して改めてCEOへ提案します。関心、具体申込、実支払、更新を分け、申込や応援を売上と呼びません。CAC（顧客獲得に実際にかかった費用）とLTV（継続期間を通じて得られる価値）も、未実測の条件を事実として作りません。

## 運用費上限と承認

**[FACT / 確認事実: 既存のCEO設定額]** 信頼できる収益化の見通しが立つまで、継続的なサービス運用費を月額5,000円以内に維持します。これは実請求額でも、予算を使ってよい許可でもありません。

対象はhosting、DB、Storage、認証、メール、AI / OCR API、監視、解析、その他継続的な本番サービス費用です。Mac本体とFounderのChatGPT / Codex利用料は、この既存上限の集計では開発費として除外されています。この区分は本PRで変更しません。

上位AI契約の採算判断は別の集計です。その契約を含むMECHORI運営費全体を考慮し、上限の対象外費用を事業採算からも除外することはしません。

- 無料枠、ローカル処理、キャッシュ、利用制限、標準的で移行可能な技術を優先する。
- 予算内でも、新しい有料・従量サービス、購入、契約、上限引上げはCEOの明示承認まで開始しない。
- 上限超過の可能性、請求不明、停止手段不明があれば、有効化せずDecision Briefへ戻す。
- 新規支出案は初期費用、固定費、従量費、無料枠の限界、最大損失、安価な代替、延期の影響を示す。
- [INFRASTRUCTURE_COST](../INFRASTRUCTURE_COST.md)の料金・無料枠は過去スナップショット。Decision時点で公式条件と実契約を確認し、現在費用として流用しない。

## 最初の会社Milestone

**CURRENT DECISION**: 現在の低コスト運営で事業を前進させ、ChatGPT Pro等の上位AI契約へ移行しても、MECHORI事業単体で現金赤字にならない状態を作ります。

上位AI契約の価格を固定値として記録しません。Decision時点の実料金、契約期間、税・為替・手数料・支払時期を確認します。差額だけでなく、当該AI契約の全額を含む実際のMECHORI運営費全体を使います。

```text
基本の採算評価
= External Real Revenue（外部から得た実売上）
  - Actual operating costs（実運営費全体）

実運営費全体
= AI subscription + API + infrastructure
  + payment-related variable costs + other real operating costs
```

AI subscriptionはAI利用契約、payment-related variable costsは決済・返金等に伴う実費です。その他の費用には実際に発生した支援・外注・利用者対応等も含め、無料利用を支える費用を枠外へ逃がしません。各費用は一度だけ計上し、AI契約とAPIを混同しません。

実売上と現金の時期は別に確認します。現金収支は同じ期間の外部実入金から実支払を差し引き、未入金売上、返金・未払の義務、年払いの支払時期を併記します。年額を月換算した余剰だけで、支払時に現金が不足しないと判断しません。

移行前の将来採算は、確認済み実績とDecision時点の上位契約料金から作る`ESTIMATE`です。仮の転換率・更新率で実績不足を埋めず、不明な費用があれば未判定とします。現在の入金状況、移行後の全費用、契約更新・支払時点で資金が足りるかを確認します。

| 未決定事項 | 状態 |
| --- | --- |
| 何か月連続の黒字を要求するか | `CEO DECISION REQUIRED`。期間を固定しない |
| どの程度の安全余裕を要求するか | `CEO DECISION REQUIRED`。金額・率を固定しない |
| 上位AI契約への実際の移行・購入 | `CEO DECISION REQUIRED`。採算資料の完成は購入許可ではない |

Founder時間の金銭換算は、実測時間と仮定単価による参考ROIとして別表示します。架空の時間節約益を実売上へ足したり、現金赤字を黒字へ変えたりしません。実際に支払った人件費・外注費は実費として計上します。

v0.1作成時点では実請求・入金を取得していないため、金額の初期値はUNKNOWNです。

- 対象期間・通貨・確認日:
- 各値の分類、根拠参照、計算式、未確認項目:

| 項目 | 確認する内容 | 初期状態 |
| --- | --- | --- |
| Revenue | 外部実売上、実入金、返金、単発／反復 | UNKNOWN |

| Other variable cost | 決済、返金、その他の利用増に伴う実費。固定のその他費用は別行で含める | UNKNOWN |
| Contribution margin | 売上から実変動費を引いた残り。固定費を賄う前の額で、利益とは区別 | UNKNOWN |

固定費・変動費の両方を含めた全費用との一致を確認します。損益分岐は実費と承認された提供条件から再計算し、単価・需要が不明なら算出不能です。過去価格に仮の契約数を掛けて「Proを賄える」と宣言しません。

## 判断を戻す条件

赤字、支出上限超過、原価・請求・権利の不明、Founder対応時間の拡大、需要の弱さがあれば、募集や大型実装で隠さずCEOへ報告します。より小さい対象、手動検証、既存手段、延期、縮小・停止を比較します。

貢献へのPaywall、広告・Affiliate都合のKnowledge順位変更、提供者の無断利用を採算改善策にしません。収益があっても、Mission、安全、権利、提供者の価値に反する案は採用候補にしません。
