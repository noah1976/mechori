# MONETIZATION

## 基本方針

収益化前の固定費・初期費用を可能な限りゼロに近づけます。所有者の明示的承認なしに、有料契約、課金開始、上限引き上げ、本番デプロイ、広告SDK導入、決済開始を行いません。

## 優先順位

1. 無料枠
2. ローカル処理
3. オープンソース
4. 回数制限
5. 少額の従量課金
6. 有料プラン

## 新しい有料サービス提案時に必ず示す項目

- 必要な理由
- 無料の代替案
- 初期費用
- 月額または従量料金
- 利用上限
- 停止・解約方法
- データ移行方法

## 将来の収益候補

- オーナー向け有料プラン
- メカニック向け有料プラン
- 整備工場向けプラン
- 専門家相談手数料
- スポンサー枠
- 文脈型広告
- 無料版への広告

初期MVPには広告SDKを導入しません。

## 初期実装

- 無料で始められる構成を優先する。
- 収益化に必要な権限差を後から追加できる設計にする。
- 決済や広告SDKは導入しない。

## 将来拡張

- メカニック・整備工場向けプラン
- 税務出力
- 広告導入判断
