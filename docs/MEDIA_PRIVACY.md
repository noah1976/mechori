# MEDIA_PRIVACY

## 遠隔αの写真保存

- 愛車メイン写真と簡易出来事の写真は、スマートフォンの高解像度写真を含め、ブラウザ内で最大辺と容量を制限したWebPまたはJPEGへ再生成してから、利用者別の非公開α Workspaceへ保存する。
- αでは48MB以下のJPEG、PNG、WebP、HEIC、HEIFを選択対象とする。ブラウザが読み込めない形式とRAWは対象外とし、処理できない場合は元画像を保存せず利用者へ伝える。
- 元ファイルは保存しない。再生成によってEXIF等の付帯メタデータを引き継がない。
- ナンバープレート、人物、住所を推測できる背景など、画素として写っている内容は自動で消えない。公開用ページ作成前に本人の目視確認を必須にする。
- このJSON内インライン画像は3〜5人αの暫定方式である。β前にSupabase Storageの非公開bucket、容量制限、削除、公開用派生画像へ移行する。
- 簡易出来事は非公開を初期値とし、写真を含むJournalを自動公開しない。記録をMECHORI内へ共有した場合、共有用写真は本文と同じ範囲に従う。
- P0 / Closed Alphaでは、共有用にブラウザ内で再生成した画像だけを非公開Storageへ保存し、参加状態が有効なログイン済みMECHORI利用者間で共有する。未ログインのWeb閲覧者へは公開しない。動画、原本、下書き・非公開記録の画像は共有しない。
- α共有画像はブラウザ内で再生成した512KB以下のJPEG、PNG、WebPに限定する。元ファイルとEXIFは送信しないが、画素に写ったナンバープレート、顔、住所を推測できる背景等は自動で消えないため、共有前に本人が目視確認する。
- α共有を停止したJournalの画像は、共有データから参照できなくなった時点で他の参加者から取得できないようにする。Storage上の不要オブジェクトも削除するが、削除失敗時もRLSと共有行を閲覧ゲートとしてアクセスを拒否する。
- 愛車登録写真から車種を推定する外部送信は行わない。αの車種候補は文字入力の別名照合だけで作る。

## 将来の写真による車種候補

- 写真認識結果は候補であり、メーカー、車名、世代、グレード、市場仕様を自動確定しない。
- 候補確認前は`photo_candidate`として扱い、本人が選択・訂正した正規IDだけを車両へ保存する。
- ナンバープレート、顔、背景、位置情報を車種識別の入力特徴として保持しない。
- 外部Providerを使う場合は、送信画像、保持期間、学習利用、処理地域、費用上限、削除方法を個別承認する。

## 目的

車両写真、整備中の写真、書類画像、動画を扱う際に、ナンバープレート、顔、住所、位置や会話等を公開してしまう事故を防ぐための処理・確認・公開ゲートを定義します。

## 原則

- ナンバープレートの文字列を認識・保存することを目的にしない。必要なのは領域検出と不可逆な除去である。
- 原本と公開用派生画像を別オブジェクトとして扱う。
- 自動検出ゼロ件を「機微情報なし」と判定しない。
- 公開前にユーザーが画像全体とマスク範囲を目視確認する。
- 公開URL、キャッシュ、サムネイル、バックアップから原本へ到達できない構成にする。
- 検出失敗や確認中は安全側に倒し、公開を止める。

## 対象

- 自車と背景の他車両のナンバープレート
- 顔
- 住所、氏名、電話番号
- 整備伝票、領収書、郵便物等の個人情報
- 正確な位置を推測できる文字・標識等
- EXIF、GPS、撮影端末等の不要なメタデータ
- 動画内の全フレームに映る同種の情報
- 動画の音声に含まれる氏名、住所、会話、車両・工場を特定し得る情報

## 処理フロー

```text
原本選択
  → 端末内またはローカルでメタデータ除去
  → 機微領域の自動候補作成
  → ユーザーによる追加・修正・誤検出確認
  → solid fill / 破壊的再描画 / crop
  → 新しい派生画像として再エンコード
  → 公開前ゲート
  → 派生画像のみ保存・公開
  → 原本削除または期限付き一時保持
```

単純な表示レイヤー、CSS、座標情報だけの黒塗り、元画素を保持した編集履歴はマスク完了とみなしません。

## 公開条件

次の条件をすべて満たす場合だけ公開できます。

1. 原本ではなくマスク済み派生画像である。
2. 不要なメタデータが除去されている。
3. 自動検出が正常終了している。
4. ユーザーが画像全体を確認している。
5. すべての検出候補が不可逆マスク済み、またはユーザー確認済みの誤検出である。
6. マスク済み候補には適用方式が記録されている。

検出機能が未実装、未実行、失敗、対応外書式の場合は公開不可とします。非公開の一時下書きとして端末内に保持する選択肢は別に設計できます。

動画は代表フレームだけで公開判定しません。全区間のフレーム検査、音声確認、位置・撮影端末等のメタデータ除去、公開用ファイルへの再エンコードが完了するまで公開不可とします。

## ローカルプロトタイプ

- 現行αの詳細Journalは保存経路を守る一時的な技術上限として画像・動画を6件まで添付できる。これは恒久的なProduct-level枚数制限ではなく、private object storage、正規化attachment、容量・帯域guardrailへ移行後に撤廃を判断する。画像は愛車写真と同じ端末内処理で縮小・再エンコードしてから保存し、元画像をIndexedDBへ残さない。動画は今回の自動軽量化対象外とする。
- メディア本体はlocalStorageへ埋め込まず、ブラウザのIndexedDBへ保存する。
- 非公開の添付は外部送信しない。P0 / Closed Alphaで記録をMECHORI内へ共有した場合に限り、ブラウザで再生成した小容量画像を非公開Storageへ送信する。AI・検出Providerへの送信は行わない。
- 自動マスキングは未実装である。ログイン済みMECHORI利用者間の共有では目視確認済みの再生成画像だけを扱い、未ログイン一般公開や公開ナレッジへの画像利用は引き続き不可逆マスキング等の公開条件を満たすまで行わない。動画は非公開に限定する。
- DEMO生成画像は実ファイル投稿とは別の`public_ready`サンプルとして扱い、実在車両資料に見せない。
- ブラウザのサイトデータ削除やDEMOリセットにより、端末内メディアも削除され得る。本番の保管方式ではない。
- `/privacy-review`では複数の疑似候補を個別に不可逆マスク済みまたは誤検出確認済みにし、住所、書類、背景車両等の見落とし候補を手動追加できる。
- すべての候補解決、公開用派生画像、メタデータ除去想定、自動検出完了想定、画像全体の目視確認が揃うまで公開可能表示にしない。
- 画面上の領域と処理はすべてDEMOであり、実画像の検出、再エンコード、メタデータ除去、保存、公開を行わない。

## 保持しない情報

- ナンバープレートの認識文字列
- マスク前の文字切り出し画像
- 顔認識用の特徴量
- EXIFの位置情報
- 公開に不要な検出Providerの生レスポンス

監査には、対象画像ID、領域種別、処理状態、マスク方法、確認日時、確認者の内部ID等、必要最小限のメタデータだけを残します。

## 実装前評価

- 日本、EU、英国等の異なるプレート形状・向き・照明
- 遠景、斜め、反射、汚れ、一部隠れ
- バイクの小型・縦長プレート
- 背景に複数台が写る写真
- 車両部品やステッカーの誤検出
- 顔、住所、書類が同時に写るケース
- 端末性能、処理時間、オフライン可否
- マスク後画像から文字を復元できないこと

実物画像を得るまでは検出ライブラリや精度目標を確定しません。評価用画像も本人の許可を得て扱い、原本の保管場所と削除日を決めます。

## 未確定

- iOS、Android、Webごとの検出Provider
- Web版でのローカル処理範囲
- 非公開下書きの端末内保持期間
- 対応地域・プレート書式
- 自動候補の評価指標と公開前合格基準
- 原本削除失敗時の運用
