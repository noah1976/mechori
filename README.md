# MECHORY

MECHORY（メカリィ）は、車両メンテナンスの記録と事例を、同じ車種・年式・仕様のオーナーやメカニックが検索しやすい形で蓄積するナレッジサービスです。

- タグライン: Fix. Share. Drive on.
- 日本語表現: 直して、シェアして、また走ろう。

現在は、製品方向、画面構成、データ構造、操作性を検証するローカルWebプロトタイプです。故障診断、修理指示、整備書または専門家の代替を提供しません。

## 必要な環境

- Node.js 20.19以上、または22.13以上を推奨
- npm 10以上

このリポジトリではnpm workspacesを使用します。

## 起動方法

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。通常は `http://localhost:3000` です。

## 確認できる機能

- ホームと登録車両の概要
- My Garage
- 整備履歴一覧・詳細
- 整備記録の手動追加・編集
- 症状、キーワード、部品番号、解決状態、危険度による検索
- 日本語・英語UIの切り替え
- `LOW`、`CAUTION`、`CRITICAL` の安全表示
- 非公開デフォルトと、共有候補の運営確認待ち状態
- OCR・PDF・音声・CSVの将来インポート予告
- OCR・AI候補の修正、確認、除外を試す抽出結果確認DEMO
- 履歴の整理レベル、節目、未解決件数を確認する車両履歴サマリー
- 個人情報を含めない共有文プレビューと、所有者データのJSON出力
- 工場へ画面提示・印刷できる車両履歴
- 本人が自由に書くGarage Journalと、整備記録の任意リンク
- プロフィール、個別車両、車種のフォロー候補と時系列フィード
- Journalの非公開、フォロワー限定、公開の範囲選択
- Journalへの写真・画像・動画の複数添付、説明、端末内保存

## データ保存とリセット

追加・編集した構造化データはブラウザのlocalStorage、Journalのメディア本体はIndexedDBへ保存します。どちらも外部へ送信しません。localStorageの保存キーは `mechory.prototype.v1` です。

My Garageの「デモデータをリセット」を押すと、追加・編集内容を削除し、初期DEMOデータへ戻せます。ブラウザのサイトデータから同じキーを削除してもリセットできます。

## DEMOデータ

FIAT Barchettaを初期実証車種として表示しますが、車両画像と整備記録はすべて操作確認用のDEMOです。実在する整備事例、修理結果、部品番号、整備工場情報ではありません。具体的な危険作業手順も含みません。

車両画像はMECHORYプロトタイプ用に生成した、ブランド表示のない汎用ロードスター画像です。FIAT Barchettaの資料写真として使用しないでください。

ブラウザ内データはlocalStorageの試作スキーマv4を使用します。旧プロトタイプのデータが残っている場合は、複数作業、メーター期間、プロフィール、Garage Journal、メディア参照、フォロー関係を持つ形へ起動時に自動移行します。これは本番DBの移行仕様ではありません。

Journalには画像10MB、動画100MBまで、合計6件を添付できます。この制限はローカル検証用の暫定値です。ナンバー・顔・位置情報等の自動除去が未実装のため、ユーザーが選択した実ファイルを含む投稿は非公開だけ保存できます。DEMOリセットはIndexedDB内の添付ファイルも削除します。

`/privacy-review`の候補領域はUI確認用の固定DEMOで、実際のナンバープレート検出ではありません。画像のアップロード、外部送信、サーバー保存、公開は行いません。

`/import/review-demo`は固定のOCR・AI候補を使った確認操作DEMOです。実ファイルの読取、AI処理、整備記録への保存は行いません。

`/garage/history`のHistory Levelと節目は、個人の履歴整理状況だけを表します。整備能力、車両状態、投稿の信頼度、検索順位、Professional認証を表しません。

## 構成

```text
apps/
  web/       # Next.js UI
packages/
  core/      # 車両・整備記録の型、検証、検索、DEMOデータ
  shared/    # DataProvider、localStorage、IndexedDBメディア実装
  i18n/      # 日本語・英語の基本辞書
docs/        # 製品、安全、プライバシー、作業状態の文書
```

業務ルールをNext.js固有コードから分離し、将来のExpoアプリとSupabase Providerへの差し替えを想定しています。

## 外部接続

このプロトタイプは、次のサービスへ接続しません。

- Supabase
- Vercel
- OpenAI API
- OCR Provider
- メール、決済、広告、アクセス解析

秘密情報や環境変数は不要です。本番デプロイも行いません。

## 既知の制限

- 認証、招待、複数ユーザー権限は未実装
- データはブラウザ単位で、別端末と同期しない
- 車両は1台のDEMO表示のみ
- 自動翻訳は未実装。UI辞書と投稿原文は分離
- OCR、AI構造化、メディアの公開前自動処理は未実装
- 運営確認、通報、法的対応は状態と導線の設計段階
- 完全一致度や別年式へ広げる検索アルゴリズムは未実装
- Journal本文からのAI候補抽出、コメント、DM、ランキング、推薦アルゴリズムは未実装

詳細な方針は [AGENTS.md](AGENTS.md) と [docs/](docs/) を参照してください。
